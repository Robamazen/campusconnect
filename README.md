# CampusConnect

AI-Enhanced Campus Community Platform — MERN stack project for GIU Software Engineering.

## Team

## Tech Stack

MongoDB · Express.js · React · Node.js (MERN)

## Setup

### Backend

1. `cd backend`
2. `npm install`
3. Create a `.env` file with `MONGO_URI` and `JWT_SECRET`
4. `npm run dev`

### Frontend

1. `cd frontend`
2. `npm install`
3. `npm run dev`
