# CampusConnect

AI-Enhanced Campus Community Platform — MERN stack project for GIU Software Engineering.

## Team

## Tech Stack

MongoDB · Express.js · React · Node.js (MERN)

## Setup

1. `npm install`
2. Create a `.env` file with `MONGO_URI` and `JWT_SECRET`
3. `npm run dev`
